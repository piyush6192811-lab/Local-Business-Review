# Local Business Review Sentiment Analysis

## Overview

This project focuses on sentiment analysis of local business reviews using Machine Learning and Natural Language Processing (NLP). The model classifies customer reviews into Positive and Negative sentiments, helping businesses understand customer feedback.

## Dataset

Amazon Fine Food Reviews Dataset

The dataset contains customer reviews and ratings used for sentiment classification.
