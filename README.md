# 📖 Project Overview

Local Business Review Sentiment Analysis is a Machine Learning project developed to automatically classify customer reviews into **Positive** and **Negative** sentiments.

The project applies **Natural Language Processing (NLP)** techniques to clean review text, extract meaningful features using **TF-IDF Vectorization**, and train a **Logistic Regression** model for sentiment prediction.

This system helps businesses understand customer satisfaction and improve their services based on customer feedback.

---

# 🎯 Objectives

- Analyze customer reviews
- Perform sentiment classification
- Build a Machine Learning prediction model
- Evaluate model performance
- Visualize prediction results
